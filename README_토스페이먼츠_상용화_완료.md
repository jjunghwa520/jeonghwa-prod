## 🔧 해결한 문제

### 문제: CSP 위반으로 토스 결제창이 열리지 않음

**발견**:
```
Console 에러:
"Refused to connect to 'https://apigw-sandbox.tosspayments.com' 
because it violates the Content Security Policy"
```

**근본 원인**:
```
config/initializers/secure_headers.rb의 CSP 설정에서
토스페이먼츠의 추가 도메인들이 허용되지 않음
```

**해결 (코드 수정)**:
```ruby
# CSP connect_src에 추가:
https://apigw-sandbox.tosspayments.com  # 결제창 API
https://log.tosspayments.com            # 로깅
https://event.tosspayments.com          # 이벤트

# CSP frame_src에 추가:
https://sandbox.tosspayments.com        # 샌드박스 iframe
https://pay.toss.im                     # 결제창 iframe
```

**배포 상태**:
