## 💡 빠른 제작 팁

### Google Slides 사용 시
1. Google Drive 접속
2. "새로 만들기" → "Google Slides" → "빈 프레젠테이션"
3. 스크린샷 드래그앤드롭으로 삽입
4. 화살표: 삽입 → 도형 → 화살표
5. 완성 후: 파일 → 다운로드 → Microsoft PowerPoint (.pptx)

### PowerPoint 사용 시
1. PowerPoint 열기 → "새 프레젠테이션"
2. 디자인 탭 → 테마 선택
3. 홈 탭 → 새 슬라이드 → 빈 슬라이드
4. 삽입 → 그림 → 파일에서
