## PPT 제작 팁

### 디자인 가이드
1. **일관된 테마**: 깔끔한 화이트 배경에 파란색 포인트
2. **폰트**: 
   - 제목: 나눔스퀘어/나눔고딕 Bold (24-32pt)
   - 본문: 나눔고딕 Regular (14-18pt)
3. **레이아웃**:
   - 왼쪽: 스크린샷 (60%)
   - 오른쪽: 설명 텍스트 (40%)

### 화살표 및 강조
- 각 단계에 번호 표시 (①, ②, ③...)
- 주요 버튼은 빨간색 화살표로 강조
- 입력 필드는 초록색 테두리로 강조

### 흐름 표시
- 슬라이드 하단에 진행 단계 표시
  ```
  [홈] → [상품목록] → [상품상세] → [로그인] → [결제] → [결제창] → [완료]
  ```
