# 프로젝트 이름 정정 안내

## ❌ 문제 발견

제미나이 CLI 작업 중 발견된 문제:
- 실제 GCP 프로젝트 이름: **`jeonghwa-prod`**
- 문서/가이드에서 잘못 사용된 이름: `jeonghwa-library-prod-xxxxx`

## ✅ 정정 사항

모든 문서에서 프로젝트 이름을 수정했습니다:

### 실제 프로젝트 정보
- **프로젝트 이름**: `jeonghwa-prod`
- **프로젝트 ID**: `jeonghwa-prod` (또는 GCP가 자동 생성한 ID)

### 수정된 문서들
1. ✅ `docs/배포_권한_설정_가이드.md`
2. ✅ `docs/USER_SETUP_CHECKLIST.md`
3. ✅ `docs/SETUP_INFO.md`

## ⚠️ 중요 확인 사항

### GitHub Secrets
GitHub 저장소의 Secrets에서 `GCP_PROJECT_ID` 값이 실제 프로젝트 ID와 일치하는지 확인하세요:

1. GitHub 저장소 → Settings → Secrets and variables → Actions
2. `GCP_PROJECT_ID` Secret 확인
3. 값이 `jeonghwa-prod` (또는 실제 프로젝트 ID)인지 확인

### 서비스 계정 이메일
서비스 계정 이메일도 올바른 프로젝트 ID를 사용합니다:
```
cloud-run-deployer@jeonghwa-prod.iam.gserviceaccount.com
```

**잘못된 예:**
```
cloud-run-deployer@jeonghwa-library-prod-xxxxx.iam.gserviceaccount.com  ❌
```

## 📋 확인 명령어

실제 프로젝트 정보 확인:
```bash
gcloud projects list
```

현재 설정된 프로젝트 확인:
```bash
gcloud config get-value project
```

프로젝트 상세 정보:
```bash
gcloud projects describe jeonghwa-prod
```

## ✅ 워크플로우 파일은 정상

`.github/workflows/deploy-cloudrun.yml` 파일은 다음을 사용하므로 자동으로 올바른 값을 가져옵니다:
```yaml
PROJECT_ID: ${{ secrets.GCP_PROJECT_ID }}
```

**중요**: GitHub Secrets의 `GCP_PROJECT_ID` 값만 올바르게 설정되어 있으면 문제없습니다!
