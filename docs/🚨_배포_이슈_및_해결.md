## ⚠️ 발생한 문제

### GitHub Actions 배포 실패

**에러 메시지**:
```
denied: gcr.io repo does not exist. 
Creating on push requires the artifactregistry.repositories.createOnPush permission
```

**원인**:
```
GitHub Actions의 GCP Workload Identity에 
Artifact Registry 생성 권한이 없음

필요한 권한:
- artifactregistry.repositories.createOnPush
```

**영향**:
```
CSP 수정사항이 배포되지 않음
→ 토스 결제창이 여전히 열리지 않음
```
