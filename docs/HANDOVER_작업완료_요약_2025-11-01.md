## 🚀 현재 배포 프로세스

### 자동 배포 (권장)
1. 코드를 main 브랜치에 push
2. GitHub Actions가 자동으로:
   - Docker 이미지 빌드
   - gcr.io에 푸시
   - Cloud Run 배포
   - 헬스 체크 수행
   - E2E 테스트 실행
3. 결과 확인 (Actions 탭)

### 수동 배포
1. GitHub → Actions → "Deploy to Cloud Run"
2. "Run workflow" 클릭
3. 기본값 확인 후 실행
