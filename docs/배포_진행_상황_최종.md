## 🔧 문제 해결

### GCR이 실패하는 경우
1. **서비스 계정 권한 확인**
   - Storage Object Admin 권한 필요
   - 또는 Artifact Registry 권한 설정 (자동 대체됨)

2. **Artifact Registry로 자동 전환**
   - 워크플로우가 자동으로 처리
   - 저장소 자동 생성 시도

### Artifact Registry 권한이 필요한 경우
서비스 계정에 다음 역할 추가:
- `roles/artifactregistry.writer`
- `roles/artifactregistry.admin`
