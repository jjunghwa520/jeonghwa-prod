## ✅ 해결 방안

### A. 즉시 해결 (수동 마이그레이션)

#### 방법 1: Cloud Run 서비스 직접 접속
```bash
# GCP 콘솔에서 Cloud Run 서비스 접속
# → Container 탭 → Exec 명령어로 접속
gcloud run services proxy jeonghwa-app --region=asia-northeast3

# 컨테이너 내부에서
bundle exec rails db:migrate RAILS_ENV=production
```

#### 방법 2: Cloud Run Jobs 사용 (추천)
```bash
# 마이그레이션 Job 생성
gcloud run jobs create migrate-jeonghwa-app \
  --image=gcr.io/[PROJECT_ID]/jeonghwa-app:8e776aa \
  --region=asia-northeast3 \
  --command=bash \
  --args=-c,"bundle exec rails db:migrate" \
  --set-env-vars=RAILS_ENV=production,RAILS_MASTER_KEY=[KEY] \
  --max-retries=1 \
  --task-timeout=600s

# Job 실행
gcloud run jobs execute migrate-jeonghwa-app \
  --region=asia-northeast3 \
  --wait
```

### B. 장기 해결 (자동화)

#### ✅ 이미 수정 완료: 배포 워크플로에 마이그레이션 단계 추가
```yaml
# .github/workflows/deploy-cloudrun.yml
- name: Run database migrations
  run: |
    gcloud run jobs create migrate-${SERVICE} ...
    gcloud run jobs execute migrate-${SERVICE} ...
```

**다음 배포 시 자동으로 마이그레이션 실행됨**
