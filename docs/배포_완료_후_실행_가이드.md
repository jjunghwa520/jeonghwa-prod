## ⚠️ 트러블슈팅

### 문제 1: 배포 완료했는데 여전히 CSP 에러

**해결**:
```
1. 브라우저 캐시 완전 삭제
   Chrome → 설정 → 개인정보 및 보안 → 인터넷 사용 기록 삭제
   → 전체 기간 → 캐시된 이미지 및 파일 → 삭제

2. 시크릿 브라우저 모드 사용
   Cmd+Shift+N (Chrome)

3. 다른 브라우저로 테스트
   Safari, Firefox, Edge 등
```

### 문제 2: 토스 결제창이 여전히 안 열림

**확인**:
```javascript
// F12 → Console에서 실행
typeof TossPayments
// "function"이 아니면 SDK 로드 실패

document.querySelector('script[src*="tosspayments"]')
// null이면 스크립트 로드 안 됨
```

**해결**:
```
1. 페이지 강제 새로고침 (Cmd+Shift+R)
2. 네트워크가 안정적인지 확인
3. 토스 SDK 서버 상태 확인 (https://js.tosspayments.com/v1)
```

### 문제 3: 배포가 너무 오래 걸림 (10분 이상)

**확인**:
```bash
# 배포 로그 확인
gcloud logging read "resource.type=cloud_run_revision AND \
  resource.labels.service_name=jeonghwa-app" \
  --limit 10 --format json
```

**해결**:
```
1. 배포 프로세스 강제 종료
   pkill -f "gcloud.*deploy"

2. 수동 재배포
   cd /Users/l2dogyu/KICDA/ruby/kicda-jh
   gcloud run deploy jeonghwa-app --source . --region=asia-northeast3
```
